# 古籍修复开工核验台

这是面向古籍修复师、材料试验员和保护技术复核员的单机浏览器工作台。系统把病害建档、材料与工序方案、试片测量、兼容性评估、风险整改、复核批准和开工许可验真串成一条可追溯流程。数据保存在本地 JSON 文件（默认 `guji.db`，文件名沿用部署约定），不依赖外部系统。

标准构建：

```text
go build ./...
```

运行服务（默认回环地址 `127.0.0.1:19081`）：

```text
go run ./cmd/server -addr=127.0.0.1:19081
```

也可以设置 `PORT=19082` 使用 `127.0.0.1:19082`。浏览器打开 `/app` 进入工作台。运行真实链路自检：

```text
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

测试：

```text
go test ./...
```
